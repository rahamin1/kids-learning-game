# Content review status

This checklist records games that were reviewed together with the user for
question quality, answer quality, visual hints, level progression, and the
intended number of levels. A game listed under **Fully reviewed** must not be
included when reporting games that still need a full review.

## Reminder for every "נבדק"

The shared selection rule prevents a question from appearing again in the
immediately following play of the same game whenever alternatives exist. It
is now verified by `scripts/check-consecutive-game-questions.js` for every
fully reviewed game. Run that check whenever a reviewed game's bank changes;
newly reviewed games must be added to its reviewed-id list.
